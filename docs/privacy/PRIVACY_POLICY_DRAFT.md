# KickLuck Privacy Policy — Draft

_Last updated: [insert date before release]_

KickLuck is a football entertainment application that lets users select real football fixtures and randomly generate football scenarios.

## Data stored on the device
The MVP may store the following locally on the user's device:
- Saved Picks
- History of Generated / Regenerated / Saved actions
- App settings
- Short-lived football fixture cache

## Network data
KickLuck retrieves football fixture information from an external football-data provider. The provider may receive standard technical request information such as IP address as part of normal internet communication.

## Analytics
If analytics are enabled in a public release, this policy must be updated to name the analytics provider and the events/data actually collected.

## No predictive profiling
KickLuck does not use personal data to predict betting outcomes or create gambling profiles.

## Data deletion
Users can clear History and fixture cache from Settings. Saved Picks are managed separately.
